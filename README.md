# 최진혁 | AI Developer Portfolio

AI와 데이터를 실제 사용자 경험으로 연결하는 개발자 최진혁의 포트폴리오입니다.

## Stack

- React
- Vite
- CSS (responsive layout & motion)

## Run locally

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`로 생성합니다.

## Structure

- `src/App.jsx` — 페이지와 UI 컴포넌트
- `src/data.js` — 프로젝트, 기술, 논문 데이터
- `src/styles.css` — 디자인 시스템과 반응형 스타일
- `public/assets/images/` — 프로필 및 수상 이미지
- `public/assets/research/` — 논문 리뷰 PDF
