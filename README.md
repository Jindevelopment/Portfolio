# 최진혁 | 개발자 포트폴리오

AI/ML·데이터 분석에 관심 있는 명지대학교 정보통신공학과 최진혁의 개발자 포트폴리오 사이트입니다.
HTML · CSS · JavaScript(바닐라)만으로 제작한 정적 웹사이트로, GitHub Pages로 배포됩니다.

## 🔗 배포 주소

GitHub Pages 활성화 후 아래 주소로 접속할 수 있습니다.

```
https://<GitHub-사용자명>.github.io/<저장소-이름>/
```

## 📄 페이지 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 소개 · 기술 스택 · 프로젝트 · 학습 목표 · 학점/자격증/수상 |
| `contact.html` | 협업 · 연락 신청 폼 |
| `style.css` | 두 페이지 공통 스타일 (라이트/다크 테마, 반응형) |
| `script.js` | 테마 전환, 실시간 검색·유효성 검사, 폼 처리 등 동적 기능 |
| `images/` | 프로필·수상·아이콘 등 이미지 리소스 |

## ✨ 주요 기능

- 라이트 / 다크 테마 전환 (localStorage로 설정 유지)
- 기술 스택 실시간 검색 필터
- 섹션 접기/펼치기
- 연락 폼 실시간 유효성 검사 및 제출 결과 동적 표시
- 모바일 대응 반응형 레이아웃 (Flexbox · Grid)

## 🚀 GitHub Pages 배포 방법

1. GitHub에서 새 저장소를 생성하고 이 폴더의 파일을 업로드(push)합니다.
2. 저장소 **Settings → Pages** 로 이동합니다.
3. **Build and deployment → Source** 를 `Deploy from a branch` 로 설정합니다.
4. Branch를 `main`, 폴더를 `/ (root)` 로 지정하고 **Save** 합니다.
5. 잠시 후 발급되는 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속합니다.

> `index.html` 이 루트에 있으므로 별도 설정 없이 첫 화면으로 표시됩니다.

## 🛠 사용 기술

`HTML5` · `CSS3` · `JavaScript (Vanilla)`
